# GamePulse-API
Proyecto de creación de API con MonogBD, Node.js y Expres.js, pensada para que sea consumida para obtener datos de videojuegos


1. Tecnologías registradas
Tecnología	Utilidad
Node.js 26.7.0	Entorno de ejecución
Express 5.3.0	Framework backend
MongoDB Atlas	Base de datos en la nube
MongoDB Compass	Administración y visualización de datos
Mongoose 9.11.2	Modelado y conexión con MongoDB
JWT	Autenticación
Bcrypt	Cifrado de contraseñas
Express Validator	Validación de datos
Swagger	Documentación de la API
Postman	Pruebas de endpoints
Nodemon	Reinicio automático durante el desarrollo
